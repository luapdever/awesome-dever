# Montserrat

Source : https://github.com/google/fonts/tree/main/ofl/montserrat

Variante variable normale, convertie du fichier TTF officiel au format WOFF2
avec fontTools, sans sous-ensemble de caractères.
Licence SIL Open Font License 1.1 : voir `OFL.txt`.

Chargée avec `next/font/local` pour éviter une récupération distante pendant
la compilation du portfolio.
