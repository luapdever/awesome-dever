# Cormorant Garamond

Source : https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Variantes variables normale et italique, converties des fichiers TTF officiels
au format WOFF2 avec fontTools, sans sous-ensemble de caractères.
Licence SIL Open Font License 1.1 : voir `OFL.txt`.

Chargées avec `next/font/local` pour éviter une récupération distante de cette
police pendant la compilation de la page Livre.
